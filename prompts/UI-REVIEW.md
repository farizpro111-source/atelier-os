# UI Review Prompt

Review the current UI against:
- PROJECT-BRIEF.md
- DESIGN-SYSTEM.md
- UI UX Pro Max guidance
- accessibility
- responsive behavior
- component consistency

Do not redesign unrelated areas.

Return:
1. concrete issues;
2. severity;
3. smallest recommended fixes;
4. verification steps.

If browser access is available, inspect the running interface rather than relying only on source code.
