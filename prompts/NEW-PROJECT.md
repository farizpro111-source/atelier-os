# New Project Prompt

Use this starter's workflow.

First, do not write implementation code.

1. Read AGENTS.md.
2. Convert my idea into PROJECT-BRIEF.md.
3. Propose the smallest sensible architecture in ARCHITECTURE.md.
4. Consult the current UI UX Pro Max guidance and the references in docs/REFERENCES.md.
5. Create a coherent DESIGN-SYSTEM.md.
6. Build IMPLEMENTATION-PLAN.md with small phases and verification after each phase.
7. Define acceptance tests in TESTING.md.
8. Only after the plan is coherent, start Phase 1.
9. After every phase, run the defined checks before continuing.
10. Never report mock or unverified integration behavior as complete.
