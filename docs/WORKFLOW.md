# Standard Workflow

## User input
The user can describe the idea in plain language. They do not need to write technical specifications.

Minimum useful input:
1. What is being built?
2. Who uses it?
3. What is the main goal?
4. Which main screens/sections?
5. What must actually work?
6. Desired visual direction/references.
7. Where will it run?

## Agent workflow
### 1. Brief
Convert the user's description into PROJECT-BRIEF.md.

### 2. Architecture
Choose the smallest architecture that satisfies the requirements.

### 3. Design System
Consult UI UX Pro Max and visual references.
Select a coherent system.
Prefer proven components.

### 4. Implementation Plan
Split work into small phases with verification after each phase.

### 5. Build
Implement one phase at a time.

### 6. Test
Run automated checks and real browser verification.

### 7. Iterate
Fix identified problems before proceeding.

## Rule
“Looks correct in code” is not verification.
