# Component Policy

## Before creating a component
Search in this order:
1. existing project components;
2. shadcn/ui;
3. chosen project design system;
4. Astryx if approved for the project;
5. reputable third-party registry;
6. custom implementation.

## Before adopting a third-party component
Check:
- license;
- maintenance/activity;
- dependency weight;
- accessibility;
- framework/version compatibility;
- source quality;
- styling compatibility;
- security implications.

## Avoid
- copying entire templates when only one block is needed;
- multiple competing UI systems for basic primitives;
- invented component props;
- unreviewed registry packages;
- unnecessary animation libraries;
- replacing stable project primitives solely for visual novelty.
