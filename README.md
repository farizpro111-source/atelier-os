# Atelier OS

Premium Telegram Mini App operating system for barbershops and beauty salons.

## Primary runtime
Telegram Main Mini App.

## Stack
- Next.js 16 / React 19 / TypeScript
- Tailwind CSS
- PostgreSQL / Supabase
- Telegram Mini Apps
- Vercel
